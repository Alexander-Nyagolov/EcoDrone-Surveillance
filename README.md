# EcoDrone-Surveillance
Repository for all files connected to the "EcoDrone Surveillance" project. It contains all hardware and software code files and sub-directories for each Arduino and Website connection.
Using an ESP32-based GPRS module, real-time
data is transmitted from a group of sensors monitoring air pollution
indicators. The data is displayed as histograms and graphs on
a self-hosted and custom-developed website, using a native JavaScript frontend,
PHP, and MySQL backend. The module is integrated into a board with
the sensors, a battery, and a wireless charging receiver.
Over-the-air (OTA) code updates have been implemented for use during operation.
